# TambayanSLU Conversation Creator

Standalone Next.js app. The chat preview uses the layout and inline style values extracted from the supplied TambayanSLU V2 `components/tambayan/ChatRoomPage.tsx`. Editing controls are separate from the original live chat backend.

Run:

```bash
npm install
npm run dev -- -p 3001
```

Open http://localhost:3001. Export as PNG or use Share / Save on supported mobile browsers. iOS cannot be forced to save automatically to Photos by a website.
